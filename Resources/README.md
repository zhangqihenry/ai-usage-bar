# Resources

Build inputs that are not Swift sources.

| File | Purpose |
|---|---|
| `AppIcon.icns` | The app icon, committed so a normal build needs no image tooling. Generated by `scripts/make-icon.swift` (`make icon`); ten sizes from 16 to 1024 px inside one `.icns`. |

Binary assets are only committed when they are build inputs. Screenshots and
other documentation images, if added, go to `docs/images/` instead.
